== 2.8.5 NULL 的三值逻辑 ==
-- 演示表（bonus / name 里各有 NULL）--
+---+-----+-----+
|id |name |bonus|
+---+-----+-----+
|1  |Alice|8000 |
|2  |Bob  |NULL |
|3  |NULL |6000 |
|4  |NULL |7000 |
+---+-----+-----+


-- 坑：等号比较永远查不到 NULL（NULL 参与比较，结果既不是真也不是假，而是'未知'）--
+---+----+-----+
|id |name|bonus|
+---+----+-----+
+---+----+-----+


-- 正确姿势：用 isNull / isNotNull 显式判断 --
+---+----+
|id |name|
+---+----+
|2  |Bob |
+---+----+


-- 聚合时 NULL 被自动忽略：avg/sum/count(列) 都跳过 NULL，count(*) 不跳 --
+----------+----------+------------+--------+
|avg(bonus)|sum(bonus)|count(bonus)|count(*)|
+----------+----------+------------+--------+
|7000.0    |21000     |3           |4       |
+----------+----------+------------+--------+


-- 去重时 NULL 被视为'同一个值'；countDistinct 同样忽略 NULL --
按 name 去重前总行数: 4
按 name 去重后行数: 3
countDistinct(name): 2
